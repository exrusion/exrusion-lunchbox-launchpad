# Lunchbox

Lunchbox is the independent lunchpad.family launchpad application. It keeps the
working Launchify-style launch infrastructure while using its own lunchbox theme,
repository, Vercel frontend, Railway API, database, and AI agent service.

## Services

- `frontend/` — Vite and React application deployed to Vercel and Railway
- `backend/` — Fastify API deployed to Railway
- `contracts/` — Robinhood Chain launchpad contracts

The Launchify repository and deployment are not modified by this project.
