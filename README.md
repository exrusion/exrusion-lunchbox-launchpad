# Lunchbox

Independent launchpad infrastructure for `lunchpad.family`.

- Separate GitHub repository
- Separate Railway project and PostgreSQL database
- Explicit MetaMask / Trust Wallet selection
- Robinhood Chain (4663) and official Pons V2 factory
- Onchain lunchpad registration, deterministic fee splitters and verified launches
- Creator tax selectable from 2–4%; fee rails preserve the 70/20/10 creator/operator/protocol model

Deploy `backend` and `frontend` as separate Railway services.
